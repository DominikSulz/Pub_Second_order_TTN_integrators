To run the Matlab examples one must add the folders "rank_adaptive_integrator_for_TTN" via the addpath(...) function from Matlab. Further, one must download and also add the tensor toolboxes "tensorlab" and "tensortoolbox". Link to it can be found at:

Tensorlab: https://www.tensorlab.net/#download Tensortoolbox: https://www.tensortoolbox.org/
